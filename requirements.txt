# server actually imports.

#   uvicorn        Vercel supplies the ASGI server; only used by `python -m app.main`

#   qrcode/pillow  imported lazily, only when show_qr_code is on; the invoice

#   openpyxl, slowapi, tenacity   not imported anywhere in app/
#

# feature and only fail when a request hits it, which is exactly how orjson got
# left out of the first cut of this file and 500'd every response:
#   orjson            ORJSONResponse, the app's default_response_class

#   email-validator   pydantic's EmailStr
